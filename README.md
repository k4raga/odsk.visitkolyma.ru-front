# «Открой для себя Колыму»

Фронтенд сайта регионального фотоконкурса «Открой для себя Колыму». Проект был выполнен как коммерческая разработка для туристического портала Магаданской области в 2022–2023 годах.

**Статус:** завершённый коммерческий проект.

**Исходный адрес:** [odsk.visitkolyma.ru](https://odsk.visitkolyma.ru/) — текущая версия сайта может отличаться от зафиксированной в репозитории реализации.

## Задача проекта

Нужно было создать адаптивный интерфейс фотоконкурса и встроить его в существующую инфраструктуру на 1С-Битрикс. Посетитель мог познакомиться с условиями конкурса, посмотреть работы и профили участников, зарегистрироваться по электронной почте и проголосовать.

Репозиторий содержит только фронтенд. Список и профили участников, состояние голосования и регистрация обслуживались серверной частью на 1С-Битрикс, которая сюда не входит. Контент участников в локальных шаблонах — демонстрационные заглушки; рабочие данные поступали через API.

## Что реализовано

- адаптивный лендинг с условиями, этапами, номинациями, жюри и призами;
- динамический каталог участников и отдельные страницы работ;
- получение профиля, фотографий и социальных ссылок участника через API;
- регистрация по электронной почте и сохранение ключа авторизации в `localStorage`;
- сценарии голосования, зависящие от состояния, возвращённого бэкендом;
- переходы между предыдущей и следующей работой;
- модальные окна, мобильное меню, галереи и слайдеры;
- production-сборка с путями, совместимыми с шаблоном 1С-Битрикс.

## Интеграция с бэкендом

Фронтенд обращается к API того же домена:

- `GET /api/contest/participant/list/` — список участников;
- `GET /api/contest/participant/detail/` — профиль и работы участника;
- `POST /api/contest/voting/sign_up/` — регистрация для голосования;
- `POST /api/contest/voting/vote/` — отправка голоса.

Без серверной части статические разделы можно открыть локально, но каталог участников, регистрация и голосование работать не будут.

## Стек

- HTML5;
- LESS и CSS;
- JavaScript (основная клиентская логика без фреймворка);
- Webpack 5 и Babel;
- jQuery и Slick Carousel;
- интеграция с API на 1С-Битрикс.

## Структура

```text
src/
├── html/       HTML-шаблоны главной и страницы участника
├── css/        LESS-стили, переменные и миксины
├── js/         клиентская логика и работа с API
├── img/        графические материалы
└── index.js    точка входа сборки
```

Webpack формирует каталог `htdocs/` и раскладывает стили, скрипты и изображения по структуре шаблона `local/templates/visitkolyma/`.

## Локальный запуск

```bash
npm install
npm start
```

Production-сборка:

```bash
npm run build
```

Проект создавался на экосистеме Node.js 2022 года, поэтому при установке на современных версиях Node.js возможны предупреждения устаревших зависимостей.
